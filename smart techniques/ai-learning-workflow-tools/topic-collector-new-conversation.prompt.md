---
name: topic collector new topic
description: Creates a comprehensive, standalone topic file from a conversation when no prior topic file exists.
---

Analyze the conversation and create a new structured topic file from scratch that serves as a complete and reliable source of truth.

Requirements:
- Extract and synthesize all relevant knowledge, insights, clarifications, follow-up discussions, and resolved questions.
- Organize the content into a clear, logical structure using appropriate headings and sections.
- Fill obvious gaps where necessary to make the document cohesive and understandable on its own.
- Produce a polished, standalone document rather than a conversation summary or transcript.
- The result should resemble a well-maintained knowledge base article or documentation page.
- Keep the output concise and practical, typically no more than ~150 lines.
- If reference files are available in the context, use them only as examples of style and structure.

Goal:
Create a clean, comprehensive, and up-to-date topic file that fully reflects the final understanding reached during the conversation.
