---
name: topic collector and enhancer
description: Updates and enhances an existing topic file by integrating new knowledge from a conversation into a single, comprehensive source of truth.
---

Review the existing topic file and the conversation, then create an updated topic file that fully incorporates the new information.

Requirements:
- Synthesize all relevant knowledge, insights, clarifications, follow-up discussions, and resolved questions from the conversation into the existing topic.
- Reorganize and refine the content as needed rather than simply appending new information.
- Preserve valuable information already present in the topic file while updating it with newer or more accurate understanding.
- Ensure the document remains clear, consistent, well-structured, and easy to navigate.
- Fill obvious gaps where necessary to make the document cohesive and understandable on its own.
- The result should resemble a well-maintained knowledge base article or documentation page.
- Keep the output concise and practical, typically no more than ~300 lines.
- If additional reference files are available, use them only as examples of style and structure.

Goal:
Create a clean, comprehensive, and up-to-date topic file that merges the existing topic and the conversation into a single, authoritative source of truth.
